# 📝 Lista de Tarefas (React + TypeScript)

[![Status](https://img.shields.io/badge/status-production-green)]()
[![License: MIT](https://img.shields.io/badge/license-MIT-blue)]()
[![Made with React](https://img.shields.io/badge/react-%5E18.0-blue)]()

Aplicação simples de **Lista de Tarefas** feita com **React + TypeScript** e estilo com **Tailwind CSS**. Ideal como projeto de estudo — limpa, funcional e fácil de estender.

## ✅ Funcionalidades
- Adicionar tarefa.
- Marcar/desmarcar tarefa como concluída.
- Remover tarefa.
- Validação de input (aviso visual quando vazio).
- UI responsiva com transições suaves.

## 🧰 Stack
- Next
- React (Client Component)
- TypeScript
- Tailwind CSS

## 🚀 Quick Start
```bash
git clone https://github.com/bruno-kirashy/ListaDeTarefas.git
npm install
npm run dev
# abra http://localhost:3000
